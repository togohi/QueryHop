# QueryHop

QueryHop (formerly SnipSearch) is a Chrome extension that lets you search selected text quickly across your preferred websites.

## Features
- Context menu to search the selected text with the engines you choose.
- Options page where you can add, edit, or remove search engines.
- Drag and drop to reorder them.
- Import and export your engine list as JSON.

## Installation
1. Clone this repository or download the code.
2. Open the Chrome extensions page (`chrome://extensions/`) and enable **Developer mode**.
3. Click **Load unpacked** and select the project folder.
4. Alternatively, install it from the [Chrome Web Store](https://chromewebstore.google.com/detail/snipsearch/imjmhodfdgpfaopkifgnjpafiomgdjha?hl=es).

## Usage
1. Select text on any webpage.
2. Right-click and choose **QueryHop**.
3. Pick the engine you want to use for the search.
